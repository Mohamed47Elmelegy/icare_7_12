## 📋 الحقول المطلوبة - مقارنة تفصيلية

### للممرض (isNurse = true)

```
┌─────────────────────────────────────────────────────────────────┐
│                      حقول الممرض (Nurse)                        │
└─────────────────────────────────────────────────────────────────┘

الحقول المشتركة:
├─ ✓ الاسم (Name)
├─ ✓ رقم الهاتف (Phone)
├─ ✓ البريد الإلكتروني (Email)
├─ ✓ كلمة المرور (Password)
├─ ✓ المحافظة (Governorate)
├─ ✓ المدينة (City)
├─ ✓ العنوان (Address)
├─ ✓ النوع (Gender)
└─ ✓ الموقع الجغرافي (Location)

الحقول الخاصة بالممرض:
├─ ✓ هوية الممرض (Nurse ID) ← إلزامي
├─ ✓ رخصة مزاولة المهنة (License) ← إلزامي
├─ ✓ الشهادة (Certificate) ← إلزامي
└─ ✓ بطاقة النقابة (Association Card) ← إلزامي

الحقول الاختيارية (الصفحة التالية):
├─ ○ اللغات (Languages)
├─ ○ التعليم (Education)
├─ ○ سنوات الخبرة (Experience Years)
└─ ○ الدورات (Courses)

الحقول المخفية:
└─ ✗ بطاقة العمل المتعلقة (Related Job ID)
```

## 🎯 النقاط الحاسمة

### 1. متى يتم التفريق؟

```
التفريق يحدث في 3 مراحل:

1️⃣ عند التسجيل:
   ├─ الحقول المطلوبة تتغير
   └─ الملفات المرفوعة مختلفة

2️⃣ عند جلب الخدمات:
   ├─ API يفلتر حسب user_type
   └─ كل نوع يرى خدماته فقط

3️⃣ عند البحث:
   ├─ المستخدمون يبحثون حسب النوع
   └─ النتائج مفلترة بناءً على user_type
```

### 2. كيف يتم حفظ النوع؟

```
في AuthBloc:
  bool isNurse = true;  // true = ممرض, false = مساعد

في registerData:
  registerData['user_type'] = isNurse ? "nurse" : "assistant";

في Database:
  users table → user_type column → "nurse" أو "assistant"
```

### 3. كيف يتم استخدام النوع؟

```
عند جلب الخدمات:
  GET /service/list?user_type=nurse  ← يرجع خدمات الممرضات

عند البحث:
  searchBloc.selectedProviderType = "nurse"
  → يبحث عن ممرضات فقط

عند عرض التفاصيل:
  if (user.user_type == "nurse") {
    // عرض معلومات الممرض
  } else {
    // عرض معلومات المساعد
  }
```
